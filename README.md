# FoodRush
AI-powered multi-vendor food delivery system built with Flask, SQLAlchemy and a recommendation engine.

## Run
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python database/seed.py
python app.py
```

Demo accounts:
- Admin: admin@foodrush.com / Admin@123
- Restaurant: restaurant@foodrush.com / Restaurant@123

Customer accounts can be registered from the UI.
